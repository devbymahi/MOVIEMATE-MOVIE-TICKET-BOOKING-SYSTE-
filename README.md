# 🎬 MOVIEMATE - MOVIE TICKET SYSTEM

## Overview

MovieMate is an interactive Python-based cinema management and ticket booking system designed to simulate a complete movie-booking experience through a menu-driven application.

The system brings multiple cinema operations together in one place, including movie browsing, ticket booking, booking management, cancellation, seat availability, food options, payment handling, and an integrated Help & Support chatbot.

MovieMate demonstrates the use of modular Python programming to solve a practical real-world problem while keeping the interaction simple and user-friendly.

## Features

- 🎟️ Book Movie Ticket
- 📋 View Booking
- ❌ Cancel Booking
- 🔎 Check Booking Status
- 🎬 Browse Movies
- 💺 Check Seat Availability
- 🍿 View Food Menu
- 💳 Payment handling
- 🤖 Help & Support Chatbot
- 🚪 Menu-driven application
- ⚠️ Input validation and error handling

## Technologies Used

- Python 3
- Functions and modules
- Conditional statements and loops
- Lists and dictionaries
- Input validation
- Modular programming

Testing

The system is tested through movie browsing, ticket booking, booking viewing, cancellation, booking-status checks, seat availability, food-menu access, payment-related operations, chatbot interaction, invalid menu choices, and invalid or unavailable booking information.

Input validation and conditional checks are used to handle invalid inputs and maintain a logical workflow.

Objectives
Develop a practical Python-based cinema booking application.
Simulate major operations in a movie-booking system.
Apply modular programming concepts.
Combine movie, booking, seat, food, payment, and support operations.
Provide a simple and interactive user experience.
Target Users

MovieMate is designed for users who want to browse movies, book and manage tickets, check seat availability, explore food options, and access basic cinema-related assistance.

Future Scope

MovieMate can be extended with database integration, user authentication, real-time seat management, online payments, movie ratings and reviews, personalised recommendations, AI-powered support, booking history, multiple-theatre support, web/GUI interfaces, and cloud deployment.

Learning Outcomes

The project provides practical experience with Python functions, modules, loops, conditional statements, lists, dictionaries, input validation, modular design, menu-driven applications, error handling, and problem-solving.
