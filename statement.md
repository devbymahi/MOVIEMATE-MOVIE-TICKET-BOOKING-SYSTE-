# MOVIEMATE - MOVIE TICKET SYSTEM

## Problem Statement

Movie booking involves several connected activities such as browsing movies, selecting tickets, checking seat availability, managing bookings, handling payments, and accessing additional cinema services. Managing these operations separately can make the overall process less organised.

MovieMate addresses this problem by combining major cinema-related operations into a single Python-based application. It provides users with an organised way to browse movies, book and cancel tickets, check booking and seat status, view food options, handle payment-related operations, and receive basic assistance through an integrated Help & Support chatbot.

The project demonstrates how Python programming concepts can be applied to develop a practical simulation of a real-world cinema booking system.

## Scope of the Project

The scope of MovieMate is to provide a menu-driven simulation of a movie ticket booking and cinema management system.

The system covers:

- Movie browsing
- Movie ticket booking
- Booking information
- Booking cancellation
- Booking status checking
- Seat availability checking
- Food menu
- Payment-related operations
- Help and Support chatbot
- Input validation and basic error handling

The current version is developed as a Python-based academic project. Future versions can be extended with database integration, graphical or web interfaces, online payment systems, user authentication, real-time seat management, AI-based recommendations, and cloud support.

## Target Users

The primary target users of MovieMate are:

- Users who want to browse available movies.
- Users who want to simulate movie ticket booking.
- Users who want to view, cancel, or check booking status.
- Users who want to check seat availability.
- Users who want to explore cinema food options.
- Users who want to use basic cinema-related support through the chatbot.
